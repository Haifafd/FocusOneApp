A mobile application for time and task management built with React Native (Expo).

## 🌟 Concept

FocusOne helps users concentrate on **one main goal per day**. Instead of overwhelming task lists, the app encourages users to break long-term goals into focused daily actions, supported by short focus sessions and progress tracking.

## ✨ Features

- 🔐 User authentication (register / login)
- 🎯 Daily goal selection with progress tracking
- ⏱️ Focus timer (Pomodoro-style sessions)
- 📊 Progress dashboard with weekly stats
- 📝 Notes with text and images
- 🌓 Light & Dark mode
- 💾 Offline data persistence (AsyncStorage)

## 🛠️ Tech Stack

- **React Native** (Expo SDK 54)
- **Expo Router** (file-based navigation)
- **AsyncStorage** (local data)
- **React Context API** (state management)
- **react-native-svg** (custom illustrations)

## 🚀 Getting Started

### Prerequisites

- Node.js (LTS version)
- Expo Go app on your phone (iOS / Android)

### Installation

```bash
# Clone the repository
git clone <repo-url>
cd FocusOneApp/FocusOne

# Install dependencies
npm install

# Start the development server
npx expo start
```

Scan the QR code with Expo Go on your phone.
